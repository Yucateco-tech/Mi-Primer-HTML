# Mi-Primer-HTML
Repositorio de introducción para HTML dedicado al uso lúdico y practico dentro  de las clases, y proyecto a entregar 

Este es un repositorio para que valla practicando lo aprendido en las lecciones y haci complementar esta pagina para de ese modo entregar este repositorio como Proyecto Final.

Aqui un Pequeño cambio para hacer un commit, segun los criterios de entrega de proyecto final debo crear una archivo "EVIDENCIAS.md donde subire capturas como evidencia, pero desconosco como hacer eso, haci que commo alternativa subire todas las capturas a "Imgur" para generar un link que subire adjunto al link de mi repositorio de GitHub asi como el del repositorio desplegado en GitHub Pages.

Siguiendo esa "Alternativa" aqui mismo respondere al apartado de la seccion "Aprendizajes" a lo cual respindere brevemente a:
¿Que fue lo mas facil y lo mas retador? - Lo mas facil a sido la creacion de un HTML asi como una hoja de estilos CSS, asi como entender su estructura, y lo mas retador a sido todo el proceso referente a la creacion de un repositorio asi como su despliegue en GitHub y GitHub Pages

¿Qué etiquetas semánticas usaste y por qué? - Usé las etiquetas semánticas header, nav, main, section y footer porque permiten organizar el contenido según su función.
Estas etiquetas mejoran la estructura del documento, la accesibilidad y la comprensión del contenido, tanto para los usuarios como para los motores de búsqueda.

¿Cómo organizaste tus commits? - Organicé mis commits de forma progresiva y descriptiva, realizando cambios pequeños en cada uno, como estructura HTML, estilos CSS y ajustes finales.
Esto me permitio llevar un mejor control del proyecto y me facilito identificar qué se modificó en cada etapa.

¿Qué mejorarías en la siguiente iteración? - En una siguiente iteración mejoraría el diseño visual, agregando más estilos responsivos, y optimizaría la accesibilidad, por ejemplo mejorando el contraste y la experiencia en dispositivos móviles.
